GBIF Community Components

Four cards, each one HTML element. Everything below talks to the live GBIF API.

1. A taxon page from four elements

Click a taxon in the classification. The card fires a gbif-taxon-select event; this page listens and points the other three components at the same taxon. Ctrl- or cmd-click still opens GBIF.org.

Events seen on this page



    

      Searching occurrences (a filter panel, table and image gallery that share one search, a subset given as a
      predicate) is on its own page, and
      a search that opens occurrence pages, with one card for each Darwin Core group, the
      images, a map of the location and the extensions, is on another.
